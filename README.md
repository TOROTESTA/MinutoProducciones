# Minuto Producciones – Portfolio Web

Sitio web institucional y portfolio para **Minuto Producciones**, desarrollado con **Astro**.  
El objetivo del sitio es presentar trabajos realizados y servir como carta de presentación para licitaciones y contactos comerciales.

## 🚀 Stack
- **Astro**
- HTML / CSS
- JavaScript
- Deploy en **Vercel**

## 📁 Estructura del proyecto
- `src/pages` – Páginas del sitio
- `src/components` – Componentes reutilizables (Header, PostCard, etc.)
- `src/content` – Content collections (bio, work, contact, etc.)
- `public/` – Assets estáticos (imágenes, videos, fuentes)

## 🖥️ Desarrollo local
Requisitos:
- Node.js (v18+ recomendado)
- npm

Instalación:
```bash
npm install

## Correr en local:
npm run dev

## El sitio estará disponible en:
http://localhost:4321


🌐 Deploy

El proyecto está pensado para deployarse en Vercel, con integración directa a GitHub.

Cada push a la rama principal genera un nuevo deploy automático.
